# 트러블슈팅 기록

도메인별 기술 문제의 원인, 후보 해결안, 검증 상태를 누적한다.

## 기록 원칙

- 실제 해결과 검증이 끝난 항목은 근거를 함께 기록한다.
- 구현 전 예상 위험은 `검토 중`으로 기록하고, 해결된 것처럼 표현하지 않는다.
- Human이 AI 제안의 누락을 발견하고 판단을 바꾼 과정은 [AI Human 검토 기록](../AI_휴먼_검토_기록.md)에 남긴다.
